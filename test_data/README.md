# Test data

Sample policy PDFs for exercising the RAG ingest and retrieval path.
All content is fictitious and generated by `generate_policies.py`.

| File | Product | Policy no. prefix | Pages |
|---|---|---|---|
| `policies/travel_single_trip_policy.pdf` | Travel single-trip | `TR-` | 2 |
| `policies/pet_health_policy.pdf` | Pet health lifetime | `PH-` | 2 |
| `policies/gadget_electronics_policy.pdf` | Gadget & personal electronics | `GD-` | 2 |
| `policies/small_business_property_policy.pdf` | Small business property & interruption | `BP-` | 3 |

Each document follows the same seven-section layout as `sample_data/policies/*.md`
(period, covered perils, exclusions, excess, limits, claim conditions, fraud) but uses
distinct figures, so a retrieval query such as "what is the theft excess" should cite
a different clause depending on which product is asked about.

## Ingest

```bash
for f in test_data/policies/*.pdf; do
  curl -X POST localhost:8000/policies/ingest -H 'x-actor: me' \
    -F file=@"$f" -F "metadata={\"product\":\"$(basename "$f" .pdf)\"}"
done
```

## Regenerate

```bash
pip install reportlab   # not a project dependency
python test_data/generate_policies.py
```
